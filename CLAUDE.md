# Working in this repo

The project's rules live in [`.cursor/rules/`](.cursor/rules) and apply to every agent, not only Cursor. Read them at the start of a session and follow them:

- [`personal.mdc`](.cursor/rules/personal.mdc) — communication, honesty, check before you claim something exists.
- [`planning.mdc`](.cursor/rules/planning.mdc) — fewest risky steps, one source of truth.
- [`code-style.mdc`](.cursor/rules/code-style.mdc) — error message format, JSDoc, logging.
- [`decision-log.mdc`](.cursor/rules/decision-log.mdc) — write every mid-sized or bigger decision we reach in chat to [`docs/decisions/`](docs/decisions/README.md), in the same turn it is decided.

Orientation: [`README.md`](README.md) for how to run and check, [`CONTEXT.md`](CONTEXT.md) for the domain language, [`docs/spec.md`](docs/spec.md) for the spec, [`docs/adr/`](docs/adr) for architectural decisions and [`docs/decisions/`](docs/decisions) for the team's decision log.
