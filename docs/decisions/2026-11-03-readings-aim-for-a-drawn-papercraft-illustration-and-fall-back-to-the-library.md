# Readings aim for a drawn papercraft illustration first, fall back to the media library after two failed checks, and show no image when neither fits

**Why:** The Norse mythology test Course published with no images because every prompt in the image chain was told to show an image only when words alone cannot teach the objective. That rule is wrong for a teacher: a good teacher draws on the board even when talking would do, because the picture is what makes it stick. So every Reading now aims for a visual, and the blueprint no longer decides all-or-nothing.

The visual is drawn by our own illustration engine in one house style that follows the app's papercraft theme (SEN-97), and can sometimes include Jongi. We turned down the media library as the first choice: it holds few files today, and real images never share one look. We also turned down AI image generation and stock.

The order is fixed. The engine draws an illustration from a detailed description of what it must show. The Vision Judge checks it. After two failed attempts we search the media library. If the library has nothing that fits, the Lesson shows no image. A missing image never blocks a Lesson.

Techniques, such as holding drumsticks, get an illustration too rather than requiring a real photo, but only when the description spells out exactly what must be shown, and the Judge checks technique illustrations harshly. The cost: technique illustrations will often fail the Judge and fall through to the library or to no image, and we accept that over teaching a wrong grip.

This replaces SEN-121's plan of three independent drafts of the four existing prompts. Which drawing engine to use is decided after a side-by-side prototype.
