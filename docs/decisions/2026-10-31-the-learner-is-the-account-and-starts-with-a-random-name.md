# The Learner is the account, and each new one gets a random learning-themed display name such as Curious_Owl, which they can change in Settings

There is no separate User or Account entity. A Learner signs up, gets a name like `Curious_Owl` or `Creative_Avocado`, and can rename themselves in Settings to their own name or anything they like. The app shows their initials in a circle, Google-style (`CO`, `CA`).

**What we turned down:** a separate Account beside the Learner, and asking for a name during sign-up.

**What it costs:** a random name is a placeholder that many people will never change. Display names are not unique, so they can never be used to identify someone.
