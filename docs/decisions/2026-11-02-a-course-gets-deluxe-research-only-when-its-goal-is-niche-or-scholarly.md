# A Course gets deluxe research only when its focused goal is niche or scholarly; density alone stays regular

**Why:** When generation starts, Luna answers three yes/no questions about the focused Learning Goal and its scope. Is it niche (few general-audience Sources)? Is it scholarly (the best Sources are peer-reviewed or specialist)? Is it dense in exact dates, names, figures or procedures? Code makes the call: niche or scholarly is deluxe, otherwise regular. The rating runs at generation start rather than at the end of focusing, so the Learner never waits on it and no new status is needed. A failed rating counts as deluxe.

We turned down "any yes is deluxe". Most subjects are dense in names or procedures (Norse in names, Gram in procedures), so almost every Course would stay deluxe and save almost nothing. We also turned down "two or more yes" as harder to explain for little gain. The density answer is still stored, so the Usage Console can show it if we revisit the rule.

**What it costs:** a mainstream topic that is dense in facts, like both test Courses, gets the regular packs. The test-Course run on the regular tier is meant to catch exactly that case.
