# A technique photo of both hands in the same grip fits a caption about one hand; hands in different grips must still be told apart

**Why:** In the first SEN-132 live run, the search found the right photo, "Drumstick mached grip", and the technique Judge failed it only because it shows two hands while the brief's caption and alt say "a hand". The rule asked the caption to say which hand is which whenever two show. The Reading writer writes the brief before any photo is found, so it cannot know how many hands the photo will have, and matched grip is the same in both hands by definition.

So when every hand in the photo shows the technique the brief describes, a caption about one hand fits, and each `mustShow` item may be read on whichever hand shows it best. When the hands differ (traditional beside matched), the caption must still name each, and a different technique on any hand still fails. The rest of the harsh technique rule (decision 2026-11-03) stands.

We turned down two alternatives. Making the writer's technique captions hand-neutral would reword every technique brief to suit some photos. Shipping the search alone would leave a found grip photo unshown.

The cost: the Judge is a little more lenient on two-hand photos, so the technique-Judge set was re-run to check that it still lets no wrong grip through.
