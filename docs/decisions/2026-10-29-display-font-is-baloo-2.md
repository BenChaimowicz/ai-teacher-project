# Display text is set in Baloo 2 Bold, replacing Instrument Serif

**Why:** Yarden didn't like the thin high-contrast serif on the "Knibbler" wordmark and Jongi's name, and it carried every heading with them. We compared ten candidates side by side on the dark paper colours, among them Space Grotesk Bold (no new font), Fraunces, Bricolage Grotesque, Young Serif and Sora, and chose Baloo 2: round and friendly, a better match for a cut-paper hamster than a bookish serif. It costs us a more playful, less editorial tone on lesson titles and quiz questions, which are set in the same token, and one more font file to load. The weight lives in `--weight-display` beside `--font-display`, so a future swap changes one place.
