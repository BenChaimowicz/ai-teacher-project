# Commons ingest judges at most three files per visual, and keeps only clearly licensed, unrestricted still images at least 300 px on the short side

**Why:** Each Judge call is a paid high-detail vision call made while a Lesson is being written. In live searches, files past the third were rarely better than the first three, so judging more would mostly add cost and wait. We accept that a good fourth file is sometimes missed.

A licence must be one we can map without guessing. Files with any Commons "Restrictions" note (trademark, personality rights, insignia) are rejected, even when the licence itself is free. So are Flickr "No restrictions" and the bare "Attribution" tag, because they don't name a licence we can cite. GIFs are skipped, since on Commons they are mostly animations. Images whose shorter side is under 300 px are skipped, because they look blurry in a Reading. The cost of this strictness is fewer finds. We take that over hosting a file we're not sure we may show.
