# The RPG Course aesthetic is a per-Course opt-in on one of three premade fantasy maps, and only location names are generated, on the first switch

**Why:** The aesthetic is a per-Course choice the Learner turns on if they want it. It is not a Learner-wide setting, so one Course can be an RPG map while another stays plain. Between Lessons, Study shows a fantasy map. The map is one of three premade images, and Lessons sit on preset spots on that map, as many spots as the Course has Lessons. We turned down generating a map or art per Course because it costs too much for a cosmetic feature. The only generated text is one short location name per Lesson, plus a boss name for each Quiz and the Goal Check, all made in one call the first time the Learner switches the Course to the theme, and then stored. We turned down making names at publish, because that pays for every Course, including the many that never use the theme. The Lesson title stays the title, and the location name is a subtitle under it, so the theme never hides what the Lesson teaches. A Quiz shows as a boss battle, and the Goal Check is the final boss. A Course gets one of the three maps at random; the Learner does not pick, which keeps the opt-in to one step.

**The cost:** Three maps get repetitive across Courses. Each map needs enough preset spots for the longest Course we generate. The first switch to the theme waits on one model call.
