# The end-of-Course check against the Learning Goal is called the Goal Check

**Why:** The ticket called it a "final assessment", but `CONTEXT.md` keeps "assessment" off the list of concept names: it survives only as the Starting Level step's status label. We turned down "Final Quiz", which would blur it with ordinary Quizzes that play by other rules (a Quiz gates Progress and needs a pass; the Goal Check sits outside Progress and completes on its first scored attempt), and "Goal Test", which reads like an exam. The method id is `goal_check`. The cost is one more word in the domain language for a Lesson that looks like a Quiz.
