# Technique visuals are real images: library first, then Wikimedia Commons, and a found file joins the library straight away

**Why:** The side-by-side prototype drew a drumstick grip in both engines, and both came out as a stiff paper mitten. Fixing that would mean hand-authoring a pose template for every technique, at hours each, and a real photo teaches a grip better than a cutout anyway. So a visual of kind *technique* skips illustration. Depictions and diagrams keep illustration first (decision of the same day).

For a technique, the order is the media library, then a Wikimedia Commons search (plus CDC PHIL for microbiology, spec §5.6), then no image. A Commons file is kept only under a licence we may host (public domain, CC0, CC BY, CC BY-SA, never non-commercial). It must pass the Vision Judge, checked harshly against the brief's checklist. Then it is copied into our storage and added to the library with its tags, caption, author and licence, so the next Course finds it there. We turned down taking images from the research sources' web pages: they are almost always copyrighted, and the spec already forbids You.com Images and site scrapes.

A file found this way is used in the Lesson straight away, marked as not yet reviewed by a person, and listed in the Usage Console for review afterwards. We turned down holding it until someone approves it, because that would leave every new technique Course without images until a person looked. The cost: a mislabelled Commons upload could be shown before anyone catches it.
