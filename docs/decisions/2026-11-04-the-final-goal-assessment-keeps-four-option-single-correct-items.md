# The final goal assessment keeps the Quiz's four-option, single-correct items

**Why:** The alternative was adding short-answer or scenario items, which test transfer more directly but need a grader: another model call per answer, a rubric, and a way to argue with a wrong grade. Keeping the current format lets the final assessment reuse the Quiz player, the item checks and the Judge pattern as they are. The cost is that "can the Learner apply it" has to be tested through well-written integrative and scenario-style multiple-choice items, not open answers.
