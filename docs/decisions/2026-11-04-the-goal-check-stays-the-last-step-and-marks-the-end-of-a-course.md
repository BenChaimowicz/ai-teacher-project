# The Goal Check stays the last step in the reading flow and is what marks the end of a Course

**Why:** With Chapter Quizzes moved out of the flow (SEN-133), the reading flow would otherwise just stop after the last Reading, and nothing would mark the end. We turned down moving the Goal Check behind the same optional "Take quiz" entry as the Chapter Quizzes, because then a Course has no finish line. It stays as SEN-81 built it: the last Lesson, completed by any submitted attempt, outside Progress. The cost is that the Goal Check is the one assessment still placed in the flow, so it is the exception to "assessments are optional".
