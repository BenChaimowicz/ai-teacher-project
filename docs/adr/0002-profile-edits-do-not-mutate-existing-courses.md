# Teaching Profile saves do not regenerate existing Courses

Saving a Teaching Profile does not regenerate Courses the Learner already has. New Course Requests use the new answers. The Learner is told this in a confirm dialog before Save from Edit or Reassess, not after the write. First Save has no disclaimer. Cancel stays in Editing with the draft. Reset has its own confirm: answers are deleted, existing Courses are not regenerated, and New Course Request is blocked until the next Save.

Silent ignore was rejected (the Learner would think old Courses had changed). Splitting Save into per-field “this one applies now” was rejected as too much UI.
